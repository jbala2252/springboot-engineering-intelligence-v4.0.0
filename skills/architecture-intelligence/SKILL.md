# Architecture Intelligence
Run the local analyzer if available, then inspect build files, source, configuration, tests and deployment
artifacts. Produce module/package maps, declared dependencies, integration boundaries, likely coupling
hotspots and documentation drift candidates. Distinguish declared dependencies from runtime call paths.
Label static approximations and list unknowns. Never claim a static graph proves runtime behavior.
