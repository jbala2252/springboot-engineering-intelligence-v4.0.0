# Database Performance

Inspect schema/migrations, query patterns, indexes, pagination, N+1 access, fetch strategy,
transaction scope/isolation, lock contention, connection pool sizing, timeouts, batching, and
database portability. Base tuning on query plans and measurements where available. Avoid
database-specific assumptions without detecting the actual engine/version. Include correctness
and rollback considerations.
