# Java Concurrency Analysis

Inspect thread creation, executor ownership, queue bounds, rejection policy, locks, atomics,
concurrent collections, shared mutable state, ThreadLocal, callbacks, futures, cancellation,
interrupt handling, and shutdown. For scheduled jobs, inspect overlap, multi-instance deployment,
misfire behavior, idempotency, and distributed coordination. Identify deadlock, starvation,
race, leak, and unbounded-work risks. Propose deterministic tests and runtime evidence.
