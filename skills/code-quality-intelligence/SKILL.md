# Code Quality Intelligence
Use static findings as leads, not verdicts. Inspect source context and classify by impact, confidence,
frequency and remediation cost. Verify duplication candidates manually; text similarity is not semantic
duplication. Review cohesion, complexity, coupling, exception handling, resource ownership, mutable global
state and test quality. Prefer incremental, behavior-preserving refactors with regression tests.
