# Spring Boot Development

Detect exact Java, Spring Boot, Spring Framework, build plugin, and dependency versions. Inspect
existing patterns and configuration. Verify API compatibility before use. Consider bean lifecycle,
proxy semantics, transaction boundaries, configuration binding, validation, exception mapping,
timeouts, resource pools, graceful shutdown, health, metrics, and security. Add tests and update
documentation. Never assume a specific Spring Boot major version.
